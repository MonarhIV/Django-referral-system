# Django Referral System

## Описание

Приложение реализует реферальную систему с авторизацией по номеру телефона, инвайт-кодами и профилем пользователя. Фронтенд реализован на Django Templates, backend — Django + DRF + PostgreSQL.

---

## API

### 1. Авторизация по номеру телефона

#### POST `/api/auth/phone/`
- **Описание:** Отправка номера телефона, имитация отправки 4-значного кода.
- **Тело запроса:**
  ```json
  { "phone": "+79991234567" }
  ```
- **Ответ:**
  ```json
  { "message": "Код отправлен (имитация): 1234", "phone": "+79991234567" }
  ```

---

#### POST `/api/auth/code/`
- **Описание:** Ввод номера и кода, создание пользователя если новый, выдача JWT (в cookie).
- **Тело запроса:**
  ```json
  { "phone": "+79991234567", "code": "1234" }
  ```
- **Ответ:**
  ```json
  { "message": "Успешная авторизация", "is_new": true, "user_id": 1 }
  ```
- **После успешной авторизации**: JWT-токен кладётся в HttpOnly cookie `jwt`.

---

### 2. Профиль пользователя

#### GET `/profile/`
- **Описание:** Получение профиля пользователя (JWT в cookie).
- **Ответ:**
  ```json
  {
    "phone": "+79991234567",
    "invite_code": "ABC123",
    "activated_invite_code": "XYZ789",
    "invited_users": ["+79991112233", "+79990001122"]
  }
  ```

---

#### POST `/profile/`
- **Описание:** Активация чужого инвайт-кода (можно только один раз, нельзя свой, проверяется существование).
- **Тело запроса:**
  ```json
  { "invite_code": "XYZ789" }
  ```
- **Ответ (успех):**
  ```json
  { "message": "Инвайт-код успешно активирован", "activated_invite_code": "XYZ789" }
  ```
- **Ответ (ошибка):**
  ```json
  { "error": "Инвайт-код уже был активирован", "activated_invite_code": "XYZ789" }
  ```

---

### 3. интерфейс

- `/` — главная страница (авторизация по номеру телефона)
- `/profile_page/` — страница профиля (просмотр, ввод инвайт-кода, список приглашённых)

---

## Примечания
- Все защищённые эндпоинты требуют JWT в cookie (`jwt`).
- Список приглашённых строится по полю `invited_by`.
- Для автоматического создания таблицы referral_user используется SQL-скрипт `init_referral_user.sql` (см. docker-compose).

## Запуск проекта

### Запуск через Docker Compose 

1. Убедитесь, что установлены Docker и Docker Compose.
2. В корне проекта выполните команду:
   ```sh
   docker-compose up --build
   ```
3. После запуска сервисов база данных и backend будут подняты автоматически.
4. Если backend запуститься с ошибкой:
```
backend    | django.db.utils.OperationalError: connection to server at "db" (172.20.0.2), port 5432 failed: Connection refused                                            
backend    |    Is the server running on that host and accepting TCP/IP connections?
backend    |                                
```
то дождитесь запуска сервиса bd и перезапустите контейнер backend следующей командой:
```
docker-compose restart backend

```
---

Теперь вы можете открыть http://localhost:8000/ для доступа к приложению.
